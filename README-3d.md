# Snake 3D — multiplayer งูข้ามอินเทอร์เน็ต

เกมงูหลายคนบนเบราว์เซอร์ กราฟิก 3D (กติกาเป็นกริดแบน ควบคุมง่าย)
ระบบห้องแบบ Kahoot: คนหนึ่งกด **สร้างห้อง** ได้รหัส 4 ตัว แล้วเพื่อนเอารหัสมา **เข้าห้อง**
เล่นด้วยกันได้แม้อยู่คนละเครือข่าย

- เซิร์ฟเวอร์: `server.py` — **Python standard library ล้วน ๆ ไม่ต้อง `pip install` อะไรเลย**
- ไคลเอนต์: `public/` — HTML + `three.min.js` (แนบมาในโฟลเดอร์ เล่น offline ได้)
- กติกา: กินแอปเปิลเพื่อโตและทำแต้ม ชนกำแพง/ชนตัวงู = ตาย เกิดใหม่อัตโนมัติใน 3 วินาที
  แต้มไม่รีเซ็ต เล่นต่อเนื่องไปเรื่อย ๆ มี scoreboard เรียลไทม์

---

## เล่นในเครื่องตัวเอง / วง LAN เดียวกัน

```
cd snake3d
python server.py
```

เปิดเบราว์เซอร์ที่ `http://localhost:8000`

- เครื่องอื่นในวง Wi-Fi เดียวกัน เปิด `http://<ไอพีเครื่องคุณ>:8000`
  (หาไอพีด้วย `ipconfig` แล้วดู IPv4 Address เช่น `192.168.1.42`)
- ทุกคนที่เข้ามาเห็นหน้า lobby เหมือนกัน — คนแรกกด "สร้างห้องใหม่" แล้วบอกรหัสให้คนอื่น

> รันแบบนี้เพื่อนนอกวงเน็ตยังเข้าไม่ได้ ต้อง deploy ขึ้น cloud ตามด้านล่าง

## Deploy ขึ้น Render (ฟรี) — เล่นข้ามอินเทอร์เน็ต

### 1. เอาโค้ดขึ้น GitHub

สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป (เอาแค่ `snake3d/` ก็พอ):

```
cd snake3d
git init
git add .
git commit -m "Snake 3D multiplayer"
git branch -M main
git remote add origin https://github.com/<ชื่อคุณ>/<repo>.git
git push -u origin main
```

### 2. ต่อกับ Render

1. สมัคร / ล็อกอิน https://render.com (ใช้บัญชี GitHub ได้เลย ฟรี)
2. กด **New +** → **Blueprint**
3. เลือก repo ที่เพิ่ง push
4. ถ้า `render.yaml` **ไม่ได้อยู่ที่ราก repo** (เช่นคุณ push ทั้งโปรเจกต์ แล้วไฟล์อยู่ใน `snake3d/`)
   ให้ตั้ง **Root Directory** ของ service เป็น `snake3d`
5. **เลือก Region ให้ใกล้ผู้เล่นที่สุด** — ตอนตั้ง service เลือก **Singapore** ถ้าเล่นกันในไทย/เอเชีย
   (region เลือกได้ตอนสร้างเท่านั้น เปลี่ยนทีหลังต้องลบ service เดิมแล้วสร้างใหม่ — เลือก Singapore ตั้งแต่แรกจะดีที่สุด
   ping จากไทยไป US จะสูงหลัก 200–300ms ซึ่งรู้สึกหน่วงชัดเจนในเกมเรียลไทม์แบบนี้)
6. กด **Apply** แล้วรอ build เสร็จ (~1–2 นาที ไม่มี build step จริง)

### 3. เล่น

- Render จะให้ URL มา เช่น `https://snake3d-xxxx.onrender.com`
- เปิด URL นั้น กด "สร้างห้องใหม่" ได้รหัส เช่น `KPWX` → ส่งรหัสให้เพื่อน
- เพื่อนเปิด URL เดียวกัน ใส่รหัส กด "เข้าห้อง" — เล่นด้วยกันได้เลย ไม่ว่าอยู่ที่ไหน

### ข้อจำกัดของ Render free tier

- เซิร์ฟเวอร์ **หลับ** หลังไม่มีใครเข้านาน ~15 นาที
- คนแรกที่เข้าหลังหลับต้องรอ **~30–50 วินาที** ให้ตื่น (โหลดหน้าเว็บค้าง ๆ รอบแรก) จากนั้นลื่นปกติ
- ถ้าอยากให้ไม่หลับ ต้องอัปเป็น plan เสียเงิน หรือใช้ cron ping ตัวเองทุก 10 นาที
- CPU ของ free tier ค่อนข้างจำกัด (แชร์กับคนอื่น) ถ้าเล่นแล้วยังรู้สึกหน่วงหลังเช็คเรื่อง region แล้ว
  ลองอัปเป็น **Starter plan** (มี CPU/RAM เป็นของตัวเอง ราคาประมาณ $7/เดือน) — โค้ดไม่ต้องแก้อะไรเลย

### ถ้ายังรู้สึกหน่วง (latency)

เรียงจากง่าย/ผลเยอะสุดไปหายาก:

1. **เช็ค region ของ service ใน Render ว่าเป็น Singapore** (ผู้เล่นอยู่แถวไทย/เอเชีย) — ตัวนี้กระทบมากสุด
   เพราะเป็น network latency จริง ๆ ที่โค้ดแก้ให้ไม่ได้
2. เซิร์ฟเวอร์ส่งอัปเดตโลก **15 ครั้ง/วินาที** (`TICK_HZ`) และฝั่งไคลเอนต์มีการ interpolate
   ตำแหน่งหัวงูระหว่างสองอัปเดตให้ลื่นขึ้นอยู่แล้ว (ไม่ใช่แค่กระตุกทีละช่อง) — ปรับ `TICK_HZ` ขึ้นได้ถ้า CPU ไหว
   แต่ free tier ไม่แนะนำให้เกิน ~20 เพราะ CPU จำกัด
3. ถ้าเล่นคนเดียว/สองคนใกล้กันแล้วยังหน่วง มักเป็นเพราะ Render free tier ถูก throttle CPU — ลอง Starter plan

## ปรับแต่ง

แก้ค่าคงที่บนหัวไฟล์ `server.py`:

| ค่า | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `GRID_W`, `GRID_H` | ขนาดกระดาน (ช่อง) | `32`, `24` |
| `TICK_HZ` | งูขยับกี่ครั้งต่อวินาที (ความเร็ว) | `15` |
| `START_LEN` | ความยาวงูตอนเกิด | `3` |
| `RESPAWN_SEC` | ตายแล้วรอกี่วินาทีถึงเกิดใหม่ | `3` |
| `MAX_PLAYERS` | จำนวนคนสูงสุดต่อห้อง | `8` |
| `APPLES_PER_ROOM` | แอปเปิลบนกระดานพร้อมกัน | `4` |
| `ROOM_IDLE_REAP_SEC` | ห้องว่างกี่วินาทีถึงถูกลบ | `60` |

ฝั่งกราฟิก/มุมกล้องปรับใน `public/client.js` (ฟังก์ชัน `buildBoard`, ค่าแสงใน `initThree`)

## โครงสร้างไฟล์

```
snake3d/
  server.py           HTTP + WebSocket + game loop (stdlib ล้วน)
  public/
    index.html        lobby + HUD
    style.css          ธีมมืด
    client.js          three.js scene + networking + input
    three.min.js       three.js r128 (แนบมา)
  render.yaml          Render Blueprint
  requirements.txt     ว่าง (ให้ Render รู้ว่าเป็น Python)
  README-3d.md         ไฟล์นี้
```

เกมงู 2D (`main.py`, `snake.py`, `apple.py`, `EXPLAINED.md`) ในโฟลเดอร์แม่แยกกันคนละส่วน ไม่เกี่ยวกัน
